# Help

Click-to-zoom
- Single click → stepwise zoom in at cursor
- Alt + click → stepwise zoom out at cursor (no reset)
- Double click → reset
- Each zoom action pushes history so users can Cmd/Ctrl+Z to backtrack

Box zoom 

- Drag box → zoom into selected span
- Alt + click → stepwise zoom out at cursor
- Box zoom commits push history for Cmd/Ctrl+Z undo



Magnifier 
- Lens is now persistent (no longer disappears on key release)
- Meta/Ctrl key press toggles lens mode ON/OFF
- Lens follows pointer when enabled
- Mouse wheel adjusts lens magnification (stepwise)
- Enter commits the lens into an actual zoom (promotes lens to main view)
- Esc cancels the lens
- Switching away from magnifier mode automatically clears lens state


Global (fairness parity)
- R resets view (across modes)
- Cmd/Ctrl+Z undo uses the local history stack (most useful for box/click modes)
